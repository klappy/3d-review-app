## [0.26.3] — candidate

### Fixed
- A survey link opened with an unexpected setting now says which settings it accepts (token, resume_token) instead of only "unknown link parameter". (#419, lane 36 · 3d-review S36)
- Asking for the survey form with extra settings (such as a language) now says the language is chosen through translation, not on the form. (#419, lane 36 · 3d-review S36)
- The receipt returned by `GET /v2/participate/receipt` (cap.response.receipt) now names the review it belongs to; the on-screen receipt is unchanged. (#419, lane 36 · 3d-review S36)
- If the page reloads while you are setting up an assessment, the wizard now returns to the step you were on with your choices kept. (#422, lane 38 · 3d-review S38)
- The Project field in the assessment setup is now marked as required in the form itself, so the browser points to it if it is left empty, as it already does for Name and Active until. (#422, lane 38 · 3d-review S38)
- Translation requests that are far too large are now refused before being read, so an oversized request cannot slow the service. (#423, lane 39 · 3d-review S39)
- When you sign in and someone has invited you to a review, Home now says so and takes you to the invitation. (#424, lane 40 · 3d-review S40)
