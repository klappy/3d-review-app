## [0.24.1] — candidate

### Fixed
- Collect no longer makes a new participant link on every visit. Each survey keeps one link: Collect makes a link when it opens only if the survey has no active link here. Otherwise it shows the active link and its QR code. The link is kept in the browser tab, so reloading the page or coming back from the participant page shows the same link and QR code, and "Print all" prints the same URLs. It is dropped on sign-out or when you use another account. A new tab still makes its own link. The survey's Share card now says: "Everyone can use this one link, also after you reload this page. In a new tab, sharing makes a new one." (#395, lane 20 · 3d-review S20)
- Setup step 4 (Ready to launch) names the survey on each "Who will participate" row, for example "Church · Church leaders — no number given". Before, it showed only the perspective. (#395, lane 20 · 3d-review S20)
- Prepare: "Save preparation" says "Saved" beside the button when the save succeeds, and shows the error there when it fails. Before, only "Saving preparation…" appeared. Moving to another page clears the message. (#395, lane 20 · 3d-review S20)
- Participant survey fixes found on a phone. An access code that is used or not valid now shows its message inside the card, right under the Access code box; screen readers announce it and the cursor stays in the box (it used to appear below the screen with focus lost). The Print survey paper preview fits a phone screen and scrolls sideways if anything is still wider, instead of cutting off the right-hand choices; printed pages are unchanged. People who answer with an access code get a thank-you that says a code works only once, not "Reopening your link shows this receipt again". After a language is chosen, the thank-you and its Reference line are translated too, and the question counter ("Question 3 of 17") is one sentence that follows the language's word order. Switching from one language to another names the language that stays on screen while the new one loads, not English. Changing the language, or a translation arriving, failing or being retried while someone is answering, no longer erases the answers given so far, the Other text or the About-you choices. (#394, lane 21 · 3d-review S21)
- A workshop room on one network is throttled less: passage files opened through their signed link no longer count against the 60-per-minute anonymous allowance of the room's address (only bad or expired links do), and translation requests that carry a participant's or signed-in person's credential are now counted per person instead of per address (the participant page starts sending its credential in a follow-up; without it, translation is counted per address as before). An assessment that has or had passages can now be deleted: the delete preview counts its passages and the delete removes them and their stored files (before, it failed with a database error). Adding a passage with an empty JSON body is a clear "JSON object body required" error instead of a server error. A machine translation that only repeats an English sentence is no longer served or stored as the translation; single words and short phrases that are spelled the same in both languages (French "Question", Spanish "Hospital") are kept. Undoing a change to an assessment's or project's translation languages now restores the previous languages. (#396, lane 22 · 3d-review S22)
- The participant survey's translation requests now say which participant is asking. When the page holds the participant's own survey session, each request to translate the page sends that participant's token, so the server can count each participant separately instead of counting every phone on the same Wi-Fi as one visitor (the server half is a separate change). A page without a participant session sends nothing extra, exactly as before, and a facilitator's sign-in is never sent with these requests. (#397, lane 23 · 3d-review S23)
- Sign-in from the tour: where email sign-in links are on, the tour's "Sign in" button now opens the "Email me a sign-in link" page, like every other way to sign in. Before, it went straight to the Cloudflare one-time code screen. Where email links are off, it is unchanged. (#398, lane 24 · 3d-review S24)
- Sign-in when you open "Start a review" from another page without being signed in: where email sign-in links are on, the page now shows the "Email me a sign-in link" form first, with "Sign in with a code instead" under it, the same as when the page is opened directly. Before, it showed one "Sign in with email code" button that opened a different page. (#398, lane 24 · 3d-review S24)
- Setup: the languages participants may switch to are now saved on the new review only, not also on a new project. Before, a language chosen during setup stayed on the project, so unticking it later on Prepare did not remove it for participants, in that review or in any later review in the project. (#398, lane 24 · 3d-review S24)
- Collect: the participant link kept in the browser tab now belongs to the signed-in person only. A link made by one account is never kept or reused for another account signed in in the same tab. (#398, lane 24 · 3d-review S24)
