### Fixed
- Account menu stacks above the shell context on phone widths so Sign out and Use another account receive pointer input; header keeps its standard heights and no horizontal overflow at 195px.
- Workspace, workspaces, projects and project pages keep their own visible heading when the kit shell is not hosting the page (non-kit entry such as /assess/); the kit host owns the title only when it is actually mounted.

- Every Retry control on a failed page is bound with one shared pending guard, so the second control (languages) works when assessments and languages both fail; stale retry results after navigation change nothing.

### Security
- Existing authentication, permissions, account read, sign-out and participant routes are unchanged; no fixture data, global state or role simulation in product. Presentation only.
