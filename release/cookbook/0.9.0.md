## [0.9.0] — candidate

### Added

- A source-pinned synthetic assessment example with three surveys, twelve responses, an inspectable report and sample answers, using the real assessment/report/participant UI.
- An isolated sample survey with the real question, review, edit and receipt flow; practice answers stay in memory and are never submitted to a live API.

### Changed

- Public tour and sample links, including the direct legacy example URL, use the shared application screens. The legacy homepage's overall visual design is preserved.
- Generic legacy navigation is retired where current screens exist; invitation acceptance and access-code participation remain compatible.
- The eight-check browser plan is closed with separately attributed historical and independent exact-head local evidence; real-human satisfaction, confusion and frustration remain NOT MEASURED.

### Fixed

- The legacy sample assessment no longer promises a populated assessment while displaying only narrative stage descriptions.

### Security

- Demo transport rejects unknown reads and all assessment mutations without network fallback. It does not read or change real staff credentials or participant drafts.
