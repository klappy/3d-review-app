## Fixed

- The homepage overview initializes an explicit video/mp4 source with metadata preload. Empty or failed media is loaded and played synchronously inside the user click before focus or scrolling; playback is never automatic. The approved v5 MP4, poster and optional same-origin captions are unchanged.
- Player recovery separates an activation denial from a real media failure, ignores interrupted or superseded play requests, offers an explicit retry button and retains the direct-video fallback. Native media error codes are shown when available. These changes correct reproducible recovery-state defects; they do not yet prove the reported iPhone Safari embedded-playback failure is resolved.
