## Contract and boundaries

The optional precondition is canonical at cookbook `e9c09cb97ef206abb418de741bb93629bd1c9e23`, [the attributed-write amendment](../AMEND-2026-09-18-feedback-attributed-write.md). Field-level contract projections pin that exact source independently of this semantic release. Existing four MCP tools, anonymous feedback, support-only readback, stripping and bounds remain intact. The form sends only explicit optional fields, never inferred scores, page content, assessment answers or credentials. The authenticated request principal supplies attribution; a preflight-only guarantee is not claimed. The flag is not persisted.

Confirmed receipts display a reference without echoing feedback. Refusal retains draft text. Uncertain responses require explicit retry with duplicate warning; no automatic retry/idempotency claim. Drafts are page-local and lost on navigation/reload. No live feedback writes, new support UI, voice, AI triage or public ticketing are included.
