## [0.26.1] — candidate

### Fixed
- When the translation service answers slowly, the survey no longer waits forever for the rest of its reply; the same time limit now covers the whole answer. (#415, lane 33 · 3d-review S33)
- If saving a passage file fails partway, the uploaded file is cleaned up instead of being left behind in storage. (#415, lane 33 · 3d-review S33)
- Taking a survey's link twice at the same moment no longer creates two live links; both requests get the same link. (#415, lane 33 · 3d-review S33)
- The assessment setup now shows that "Active until" is required, next to "Starts (optional)". (#414, lane 34 · 3d-review S34)
- When a passage link is refused (for example one starting with http:// instead of https://), the link, title and passage you typed stay in the form so you can correct them instead of typing them again. (#414, lane 34 · 3d-review S34)
- On the participant survey, the "answer required" mark on a question clears as soon as you start typing an answer, not only when you leave the field. (#414, lane 34 · 3d-review S34)
- Printing a survey in another language now follows the language picker on screen even if the page refreshed while the form was loading, and the picker and Print survey button unlock correctly afterwards. (#414, lane 34 · 3d-review S34)
- Clicking Print survey twice quickly no longer prints the form twice; the button stays locked until the form is ready. (#414, lane 34 · 3d-review S34)
