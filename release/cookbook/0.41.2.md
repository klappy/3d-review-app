## Security

- The new public read-only endpoint fetches only the hard-coded approved film URL. It forwards only Range and If-Range, never client Cookie, Authorization, Referer, Origin or query-selected targets; redirects are rejected. Unexpected non-video or encoded media responses return a generic 502. Range errors preserve 416 and the validated total length while discarding upstream error bodies and content types. Responses are streamed with no-store caching and nosniff. This is not an arbitrary proxy.
- No authentication/session/invitation/report behavior, schema, bindings, persistent credentials, deployment triggers, DNS, WAF, cache rules or CORS settings change. No autoplay or crossorigin attribute is added. Approved video bytes, poster and caption assets are unchanged. Required independent external-call security review, final exact-head checks and live verification remain separate gates.
