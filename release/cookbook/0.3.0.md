# Release record — 0.3.0

Canonical candidate for the scoped Permissions increment, app issue [68](https://github.com/klappy/3d-review-app/issues/68) and PR [69](https://github.com/klappy/3d-review-app/pull/69). Depends on the accepted web baseline released separately as 0.2.0. MCP panels and participant migration are independent workstreams and excluded. This candidate is not a release or deployment receipt.

## [0.3.0] — candidate

### Added
- Scoped Permissions controls for workspace, project and assessment grants, pending invitations, role changes, revocation and ownership transfer.

### Changed
- Permission actions refresh server-owned roster and role state in place while keeping their outcome, receipt and trace visible.

### Fixed
- Successful permission actions no longer erase their confirmation through a blank-model route reload; transfer receipts resolve to grant rows.

### Security
- Danger actions retain preview/confirm with identical parameters; scopes remain explicit with no permission inheritance. Post-action access refusal hides stale controls while retaining the completed action receipt.

## Compatibility and promotion

MINOR: additive compatible Permissions UI using existing APIs; no new capability, schema, backend, scorer or framework. Exact-head independent review, required checks and root release disposition precede normal Git-connected DEV/production promotion. No live grants or invitations are created by release verification fixtures. Production promotion remains a separate root-owned PR.
