- Fixed - A workshop room on one network is throttled less: passage files opened through their signed link no longer count against the 60-per-minute anonymous allowance of the room's address (only bad or expired links do), and translation requests that carry a participant's or signed-in person's credential are now counted per person instead of per address (the participant page starts sending its credential in a follow-up; without it, translation is counted per address as before). An assessment that has or had passages can now be deleted: the delete preview counts its passages and the delete removes them and their stored files (before, it failed with a database error). Adding a passage with an empty JSON body is a clear "JSON object body required" error instead of a server error. A machine translation that only repeats the English is no longer served or stored as the translation. Undoing a change to an assessment's or project's translation languages now restores the previous languages.
