- Added - Support staff can list which feedback arrived after a given time: `GET /v2/ops/feedback?since=<ISO-8601>&limit=<1..200, default 50>&after_id=<id from the previous page>` (MCP `read cap.ops.feedback_list`) returns, oldest first, only each row's id, time and scope type — never the feedback text, who sent it or its provenance. Read a row's content with the existing per-id read (`cap.ops.feedback_get`). Paging uses `next` (time plus id), so rows that share a timestamp or are unreadable never stall or skip a page; `has_more` says whether another page exists. Support role only; others get the existing refusal.
