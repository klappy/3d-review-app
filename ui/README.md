# Temporary functional UI shell

This is an integration adapter, not the Design lane's visual system or approved copy. It uses the live `/v2` HTTP API only; no browser-only business logic or fixture responses. The Design lane may replace `ui/`.

Run the Worker with an ignored local `.dev.vars` containing independent `SESSION_SECRET` and 32-byte base64url `CODE_ESCROW_SECRET` (see `docs/code-escrow-local.md`). On a fresh local D1, run `npm run migrate:local`, `npm run migrate:escrow:local`, then `npm run seed:local`; start `npm run dev` and open `http://localhost:8787/`. Wrangler serves only `index.html`, `app.js`, and `style.css` as static assets; `/v2/*` and `/mcp` remain Worker routes. `ui/server.mjs` is a local-only proxy fallback for testing and is excluded from deployment assets.

Public dev is a synthetic sandbox, not a private account: sign in as `demo.owner@example.invalid` using the `dev_only_code` shown by the Worker in `ENVIRONMENT=dev` (no email is sent). Only `.invalid` identities are accepted there. This reserved-domain seed fixture owns the synthetic project and Collect-stage assessment; it is not production identity provisioning. Create an assessment, select a template, explicitly move from Prepare to Collect, issue code IDs, preview credential-release impact, then confirm export to reveal code values once. Copy one code into the participant form, answer, review, submit, and recover the receipt after reload. Exported codes are not cached by this shell and cannot be recovered by repeating export. Results remain held/suppressed; link delivery and production authorization are not demonstrated. Do not enter real participant information or production keys.
